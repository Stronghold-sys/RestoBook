SETUP DUITKU PAYMENT GATEWAY - CALLBACK URL
=============================================

URL CALLBACK UNTUK DUITKU:
==========================

Jika pakai domain pages.dev:
  Callback URL : https://restobook.pages.dev/api/duitku/callback
  Return URL   : https://restobook.pages.dev/customer/orders

Jika pakai domain custom (setelah aktif):
  Callback URL : https://restobookid.my.id/api/duitku/callback
  Return URL   : https://restobookid.my.id/customer/orders

PENJELASAN:
- Callback URL = URL yang dipanggil Duitku secara otomatis saat 
  status pembayaran berubah (sukses/gagal/expired). Ini server-to-server.
- Return URL = URL yang ditampilkan ke pelanggan setelah selesai bayar.

CARA SETTING DI DUITKU DASHBOARD:
1. Login ke https://dashboard.duitku.com
2. Menu Project > pilih project Anda
3. Isi Callback URL dengan URL di atas
4. Isi Return URL dengan URL di atas
5. Simpan

CATATAN: Anda perlu membuat file API route untuk callback dulu.
Minta saya buatkan jika sudah siap.
